# 大學失物招領平台

這是一個適合校園使用的失物招領原型頁面，包含：

- 拾獲者通報表單
- 失主通報表單
- 校園地圖標記失物/遺失位置
- 最新失物與拾獲紀錄
- 手機與桌面雙版樣式

## 本機預覽

在專案資料夾內執行：

```bash
py -m http.server 8000
```

接著打開：

- 本機： http://localhost:8000
- 同一 Wi‑Fi / 區域網路： http://你的電腦IP:8000

## 查詢這台電腦的區域網路 IP

Windows PowerShell：

```powershell
ipconfig
```

尋找類似：

```text
IPv4 位址 . . . . . . . . . . : 192.168.1.35
```

這時手機或另一台電腦可直接打開：

```text
http://192.168.1.35:8000
```

## 讓其他人可從網際網路看到

如果你希望不在同一區域網路也能看到，通常有兩種方式：

### 1. 靜態部署到雲端

最簡單方式是部署到：

- Vercel
- Netlify
- GitHub Pages

這些平台會給你一個公開網址，例如：

```text
https://your-project.vercel.app
```

### 2. 透過 Tunnel 暫時公開本機網站

如果你只是想快速公開：

```bash
npx ngrok http 8000
```

或使用 Cloudflare Tunnel。

之後會得到一個公開網址，例如：

```text
https://abc123.ngrok-free.app
```
